🛡️ Por que o Anti-Reward-Hacking é Central?

  • Bloqueio Ativo de Mocks de Banco (real-harness.js): Intercepta jest.mock / vi.mock e lança erro imediato caso um agente tente simular camadas críticas (database, repository, prisma, knex, sequelize).
  • Servidor Efêmero Real: Sobe instâncias HTTP reais em 127.0.0.1:0 para testes de integração ponta a ponta contra bancos de teste reais.
  • Scanner Estático +Cascata de 3 Níveis (audit-runner.js): Inspeciona automaticamente o git diff em busca de EMPTY_CATCH, SKIPPED_TEST (.skip), RAW_SQL_INTERPOLATION e aciona revisão clínica em cascata (1º AGY CLI Nativo → 2º OpenCode + OpenRouter → 3º OpenCode Free Fallback).

🚀 Como Executar a Orquestração Ponta a Ponta

Com um único comando, o pipeline inicializa/verifica o Test Harness Real, executa a suíte de testes sem mocks viciados, roda o Auditor Clínico DevSecOps sobre o git diff e notifica o AGY Hub:

# 1. Inicializar o Test Harness Real Anti-Mock no projeto
node scripts/harness-builder.js --init --path .

# 2. Verificar integridade dos testes (Zero DB Mocks / Zero .skip)
node scripts/harness-builder.js --verify --path .

# 3. Rodar Auditoria Clínica DevSecOps (Fase 3 - Claude 5.5 / OpenCode)
node scripts/audit-runner.js --path . --model claude-opus

# 4. Pipeline Completo Unificado (Harness + Infra + Auditoria + Telemetria)
node scripts/orchestrate.js --path . --init-harness
